## 依證據保留的設計

審查對 `responseFormat.text.mimeType = APPLICATION_JSON` 的懷疑沒有沿用。此格式已通過本專案真實 Gemini 呼叫；小寫 MIME 反而收到明確 HTTP 400 列舉錯誤。模型名稱另外改用 InterAct 的即時模式設定，避免舊通用設定格式錯誤。參考官方結構化輸出文件，並以端點的實際回應驗證。

只去除完整 JSON 外圍的 Markdown 圍欄；不從任意文字抽取第一段 JSON、不接受超範圍或缺少的數值分數冒充有效評分。格式無效保留錄音並允許重試。

額外發現並修正：Gemini 曾對完全靜音捏造回答，因此先在伺服器檢查 PCM 音量，靜音直接標為無法判讀，不送 AI；以線上靜音驗證確認。AI 忙碌時有備援模型，空回饋有預設提示。
